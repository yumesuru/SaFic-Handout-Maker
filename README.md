# 사이코로 픽션 공식풍 핸드아웃 메이커

온라인 세션에서 사용할 핸드아웃을 작성하고, 스타일이 포함된 HTML로 복사하거나 PNG로 저장하는 정적 웹 도구입니다. AI를 사용해 구현했으며, 제작한 HTML/PNG는 자유롭게 가공할 수 있습니다.

## 지원 양식

| 룰 | 양식 | HTML 크기 |
| --- | --- | --- |
| 인세인 | 기본, 비밀, 광기 | 300 × 최소 420px |
| 인세인 | 의식 시트: 6단계 입력 | 700 × 360px |
| 시노비가미 | 기본·에니그마·페르소나 각각 공개/비밀 | 300 × 최소 420px |
| 마기카로기아 | 기본·단장 각각 공개/비밀 | 300 × 최소 420px |
| 스트라토 샤우트 | 굴레 앞면 | 300 × 420px |
| 스트라토 샤우트 | 굴레 뒷면 | 300 × 최소 420px |
| 스트라토 샤우트 | 가사 시트: 곡명·노래, A/B/C 파트별 두 열 | 600 × 840px |

## 사용 방법

1. 첫 화면에서 룰을 선택하고 양식과 공개 여부 또는 앞면/뒷면을 고릅니다.
2. 표시된 입력란을 작성하면 미리보기에 바로 반영됩니다.
3. ‘HTML 복사’ 또는 ‘PNG 저장’을 누릅니다.

- 기호 버튼 `「」`, `【】`, `《》`는 마지막으로 선택한 입력란에 삽입됩니다. 선택한 글자가 있으면 괄호로 감쌉니다.
- 입력 내용은 룰·양식·공개 여부(앞면/뒷면)별로 따로 유지됩니다. 다른 양식으로 바꿔도 값이 섞이지 않으며, 돌아오면 해당 양식에서 작성한 내용이 복원됩니다.
- ‘전체 지우기’는 현재 화면에 표시되는 입력란만 비우며, 다른 양식의 내용에는 영향을 주지 않습니다.
- 입력 내용은 브라우저 메모리에만 있으며, 새로고침하면 초기화됩니다. 파일이나 서버에 자동 저장하지 않습니다.
- 일반 핸드아웃은 기본 너비와 최소 높이를 유지하며, 본문이 길어지면 세로로 늘어납니다. HTML 복사와 PNG 저장에도 늘어난 높이가 반영됩니다. 인세인 의식 시트, 스트라토 샤우트 가사 시트·굴레 앞면은 기존 고정 크기를 유지합니다.
- 광기 트리거는 기본 16px이며, 실제 표시가 두 줄을 넘으면 11px로 줄어듭니다.
- PNG는 기기의 화면 배율과 관계없이 HTML 너비·높이의 2배 해상도로 저장됩니다. 예를 들어 300 × 420px 핸드아웃은 600 × 840px PNG로 저장됩니다.
- HTML 복사는 브라우저 권한과 붙여넣는 서비스의 지원 범위에 영향을 받습니다. 지원되지 않는 환경에서는 HTML 코드를 텍스트로 복사하며, 대상 서비스가 스타일을 제거할 수도 있습니다.

## 로컬 실행

빌드나 패키지 설치 없이 `index.html`을 브라우저에서 열 수 있습니다. PNG 저장에는 CDN에서 불러오는 `html-to-image@1.11.11`이 필요하므로 인터넷 연결이 필요합니다.

## 파일 구성과 수정

- `index.html`: 룰 선택 화면, 각 양식의 편집 입력란, 공통 안내
- `styles.css`: 사이트 UI와 반응형 배치
- `app.js`: 양식 생성, 입력 연동, 화면 전환, HTML 복사와 PNG 저장
- `.nojekyll`: GitHub Pages에서 정적 파일을 그대로 제공
- `.gitignore`: 로컬 시각 검증용 `*-preview.png` 제외

내보낸 HTML이 다른 서비스에서도 독립적으로 표시되도록 핸드아웃 스타일은 `app.js`의 생성 함수에 인라인으로 작성합니다. 사이트 UI만 바꾸려면 `styles.css`를 수정합니다. 외부 입력은 HTML로 이스케이프한 후 렌더링합니다.

JavaScript 문법은 `node --check app.js`로 확인할 수 있습니다. 양식 변경 시 해당 룰의 미리보기, HTML 복사, PNG 저장, 입력란 지우기, 긴 텍스트의 표시를 확인해 주세요. CSS/JS를 배포할 때는 `index.html`의 두 파일 버전 쿼리도 함께 갱신해 캐시를 갱신합니다.
