# Insane Handout Maker

Insane TRPG 핸드아웃을 빠르게 작성하고 미리보기, HTML 복사, PNG 저장까지 할 수 있는 정적 웹툴입니다.

## 기능

- 공개, 비밀, 광기 핸드아웃 레이아웃 선택
- 입력 내용 실시간 미리보기 반영
- 현재 핸드아웃을 스타일 포함 HTML로 클립보드 복사
- 현재 핸드아웃을 PNG 이미지로 저장
- GitHub Pages에 그대로 배포 가능한 정적 파일 구조

## 배포

GitHub 저장소에 `index.html`, `styles.css`, `app.js`를 올린 뒤 Settings > Pages에서 배포 브랜치를 선택하면 됩니다.
